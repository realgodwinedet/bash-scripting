# Bash Scripting Assignment

## Overview

This repository contains 20 Bash scripting exercises completed as part of the Foundations of Linux, Networking & Bash Scripting course.

The scripts demonstrate practical Linux shell scripting skills including:

- User input
- Conditional statements
- Loops
- File handling
- System monitoring
- Disk usage
- Memory monitoring
- Network connectivity
- Directory management
- File permissions
